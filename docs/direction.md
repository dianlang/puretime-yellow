# PureTime·黄：演出设计

目标是一部能选择交流方式的公路视觉小说：玩家以玛丽安的视角，逐渐了解魔女和店员，而咖啡厅回忆提供旅途之外的参照。主线使用现有序章与五节；按用户要求加入可选支线，扩写日常交流及后续回应，结尾停在现有原稿的未完待续。

## 对话画面

每次最多出现两人。魔女通常居右，其他角色保持稳定站位；同场第三人的简短插话可以使用画外音，持续加入谈话后再换入画面。配对只参考本场景的对话和角色，不跨越回忆与现实的切换点。

| 场景 | 可入镜人物 |
| --- | --- |
| 公路、便利店、营地、休息站、地下室 | 魔女、店员小姐、玛丽安 |
| 咖啡厅回忆 | 魔女、小花 |
| 停车场回忆 | 魔女、店员小姐；酒保小姐为独立的画外音角色 |
| 最后的夜间广场 | 魔女、玛丽安 |

正在说话的人略微放大；倾听者保持不透明，用亮度和饱和度区分。旁白、没有立绘的发言、留在画外的插话会解除聚焦。这样不会把倾听者画成半透明，也不会让旁白看起来像上一人的台词。

## 构图参数

在 `game/presentation.json` 中编辑左右画面中心、角色缩放与垂直偏移。配置里的左右位置是 2560×1440 舞台上的目标中心；构建器会根据 PNG 尺寸换算成 WebGAL 实际需要的相对坐标。不要把目标中心直接填进 `changeFigure` 的 transform，否则会叠加默认锚点，推离画面。

玛丽安保留较大的显示比例，同时稍微下移，以免聚焦时头顶被裁掉。更换图片后重新构建，尺寸换算和边界检查会随新图片更新。

## 表情差分

魔女已使用维护者上传的三张差分；原来的 `witch.png` 保留为平静表情。

| 表情键 | 文件 | 使用方向 |
| --- | --- | --- |
| `neutral` | `witch.png` | 平静、严肃、收敛情绪 |
| `happy` | `witch_happy.png` | 微笑、得意、忍俊不禁、带笑的讽刺 |
| `surprise` | `witch_surprise.png` | 听到笔记线索、回忆中的意外回答、结尾诧异 |
| `angry` | `witch-angry.png` | 不耐烦、羞恼、争辩 |

四张图均为 1108×1419。构图依据同一角色的参数计算，表情文件名不会被误当成另一个角色。新增差分与基础图的上色及边缘略有差别，本次保留上传素材原样。

`game/expressions.json` 中的 `cues` 是人工按原文选取的演出标注，不使用关键词自动猜测。当前有 30 条标注，包含恢复平静的节点。每条包含：

- `paragraph`：原稿按空行分段的 0 起始索引，可在生成的 `game/scene/source-map.json` 中查找。
- `character`：角色键，目前标注的是 `witch`。
- `expression`：本角色在 `game/presentation.json` 中配置的表情键。
- `quote`：该段中的一小段原文，供构建器校验索引；索引或引文不符会报错。

例如第 94 段的“第一次露出惊讶表情”令魔女切换为 `surprise`；第 103 段“带我们去那里”恢复 `neutral`。第 112 段爆笑使用 `happy`，第 131 段“吃饭的时候不许说话”使用 `angry`。原文中的爆笑目前由微笑差分代表，后续可以补张嘴大笑的专用表情。

表情从标注段落开始，持续至下一条标注；同段多页保持一致，旁白也可以触发变化。场景或章节切换后恢复默认。角色暂时不在画面时只记录状态，不为换表情强行入场；再次入镜直接使用当前表情。

同一角色换表情时保持站位，取消旧图淡出与新图入场，避免双脸叠影；换图时直接套用下一句的聚焦参数。WebGAL 4.6.4 会沿用旧图保存的退场时长，因此生成器先用同路径命令更新旧图退场参数，再替换图片。两句均自动连续执行。真正换人及切场仍沿用原有演出。

新增差分时，将文件放入 `game/figure/`，在对应角色的 `expressions` 中添加键，再添加剧情标注。默认键 `neutral` 必须存在，同一角色所有差分的画布尺寸必须一致。修改后重新构建；不要直接修改生成的场景文件。

## 阅读节奏

章节用黑底文字分隔，段落只分页、不改写。人物入场、换位和聚焦连续完成，不单独要求玩家多点一次。三人的公路对话可以换人，但相同的左右组合不会反复退场入场。末尾明确显示未完待续。

## 可选支线与选择记忆

新增支线由本次游戏制作扩写，源文件为 `game/side-stories.json`，与 `source/original.txt` 的原稿正文分开维护。三处选项均安排在对话或场景自然停顿处。玩家决定交流方式，每个选项有对应文本，并记录在本局剧情变量中。

| 支线 | 原稿段落之后（0 起始） | 变量 | 选择值 |
| --- | --- | --- | --- |
| 车斗里的问题 | 105 | `pt_notebook` | 1：追问笔记；2：分享奶奶的回忆；0：暂时不问 |
| 便利店的小小停战 | 174 | `pt_truce` | 1：递纸巾；2：追问魔女；0：结束话题 |
| 门外的一小段路 | 380 | `pt_supper` | 1：帮忙拿碗；2：向店员倾诉；0：安静同行 |

后续回应有两处：

- 第 384 段之后，帮忙拿碗会得到魔女的一句评价；向店员倾诉则让玛丽安想起她关于“自己去做”和“谁也不告诉”的话。
- 第 394 段之后，按顺序选择首个符合条件的夜谈回应：递纸巾的停战（`pt_truce=1`）→奶奶讲故事的回忆（`pt_notebook=2`）→继续追问的约定（`pt_truce=2`）→笔记用途的提问（`pt_notebook=1`）。都未选择时直接继续原稿。

这版采用可记住的具体互动，没有增加数值好感度面板。魔女保持嘴硬、戒备和好奇，店员通过实际照料回应；没有新增背景真相或原稿之后的结局。主线 408 段在每一种选择组合下仍按原顺序完整出现。所有支线文本连同入口提示共 74 页，其中很多内容互斥。

每条选项和回应支持单独的说话人、文字和魔女表情。主线使用 `callScene` 进入支线；选项先跳至当前场景的标签，再调用对应对话；对话结束通过 `return` 返回。每次返回恢复原背景、立绘文件和聚焦参数，避免支线的情绪带到不相关的主线台词中。

配置中的 `afterParagraph` 和 `quote` 共同定位插入点；引文必须存在于相应原稿段落。`options` 的 `value` 是写入剧情变量的整数，`callbacks.variants[].when` 指定要匹配的变量和值。同一回应按配置顺序命中一条后停止。修改后重新构建，生成脚本位于 `game/scene/side/`。

检查器遍历九个选项组成的全部 27 条完整路径，核对原稿、选择值、分支可达性、后续回应以及画面状态恢复。未进行浏览器逐页试玩或存读档实测。

## 手机与本地修改

保留横屏阅读。手机转为竖屏时遮住舞台并停止自动播放和快进，避免旋转过程中错过内容；不支持强制横屏的浏览器会提示手动关闭系统旋转锁定。

下载并解压后，可以用 VS Code 修改源码，或在 Windows 双击 `start-game.cmd` 构建并启动本地服务。生成目录不作为修改入口。

## 后续素材方向

后续可补魔女的张嘴大笑、玛丽安的迟疑与坚定、店员的笑脸与困惑、小花的得意与尴尬，以及更贴合原稿的背景。差分尽量基于同一身体底图绘制，仅改变五官。尚未提供的表情不以换色或形变代替。主线续篇仍等待后续原稿。
