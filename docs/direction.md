# PureTime·黄：演出设计

目标是一部按原稿阅读的公路视觉小说：观众跟随玛丽安的视角，逐渐了解魔女和店员，而咖啡厅回忆提供旅途之外的参照。保留现有序章与五节，不把原稿未写完的部分补成自创结局。

## 对话画面

每次最多出现两人。魔女通常居右，其他角色保持稳定站位；同场第三人的简短插话可以使用画外音，持续加入谈话后再换入画面。配对只参考本场景的对话和角色，不跨越回忆与现实的切换点。

| 场景 | 可入镜人物 |
| --- | --- |
| 公路、便利店、营地、休息站、地下室 | 魔女、店员小姐、玛丽安 |
| 咖啡厅回忆 | 魔女、小花 |
| 停车场回忆 | 魔女、店员小姐；酒保小姐为独立的画外音角色 |
| 最后的夜间广场 | 魔女、玛丽安 |

正在说话的人略微放大；倾听者保持不透明，用亮度和饱和度区分。旁白、没有立绘的发言、留在画外的插话会解除聚焦。这样不会把倾听者画成半透明，也不会让旁白看起来像上一人的台词。

## 构图参数

在 `game/presentation.json` 中编辑左右画面中心、角色缩放与垂直偏移。配置里的左右位置是 2560×1440 舞台上的目标中心；构建器会根据 PNG 尺寸换算成 WebGAL 实际需要的相对坐标。不要把目标中心直接填进 `changeFigure` 的 transform，否则会叠加默认锚点，推离画面。

玛丽安保留较大的显示比例，同时稍微下移，以免聚焦时头顶被裁掉。更换图片后重新构建，尺寸换算和边界检查会随新图片更新。

## 阅读节奏

章节用黑底文字分隔，段落只分页、不改写。人物入场、换位和聚焦连续完成，不单独要求玩家多点一次。三人的公路对话可以换人，但相同的左右组合不会反复退场入场。末尾明确显示未完待续。

## 手机与本地修改

保留横屏阅读。手机转为竖屏时遮住舞台并停止自动播放和快进，避免旋转过程中错过内容；不支持强制横屏的浏览器会提示手动关闭系统旋转锁定。

下载并解压后，可以用 VS Code 修改源码，或在 Windows 双击 `start-game.cmd` 构建并启动本地服务。生成目录不作为修改入口。

## 后续素材方向

下一步最有价值的是补同姿势的表情差分，以及更贴合原稿的背景。差分宜先覆盖魔女的不耐烦、惊讶与缓和，玛丽安的迟疑与坚定，店员的笑脸与困惑，小花的得意与尴尬。当前没有这些图片，因此没有用换色或形变假装角色表情。新剧情仍等待后续原稿。
